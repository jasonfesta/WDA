# Reusable artwork

- `sol-sun-accent.png` and `roam-ribbon-accent.png`: generated decorative artwork, with transparency preserved.
- `icons/`: 20 native SVG icons.
- `materials/`: 10 native SVG material samples.

These are copies of the source assets used in the final studies. Each full-state SVG also embeds its decorative images, so it is portable by itself. Icons are decorative beside labels; icon-only actions receive the accessible names specified in the guides. No separate avatar photographs or font downloads are required.
