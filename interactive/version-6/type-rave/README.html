Type Rave — typographic performance concept

Status: graphic direction and specifications only. No product development is included.

Type Rave turns a short phrase into an instrument. A visitor would choose words, shape a composition, and perform it through restrained music or microphone mappings. The typography must repeatedly become readable; motion is expressive punctuation rather than permanent distortion.

The DIA / A-Trak reference is existing published artwork, not a Type Rave screen. It supports the idea that a limited typographic vocabulary can produce a wide visual range. This pack proposes its own phrase system, palettes, behaviors, controls, and output rules.

Read Product, Experience, Visual direction, Interaction states, Content and assets, Technical plan, and Acceptance. Sources separates reference facts from proposals.

Three proposed behaviors anchor the direction: Breathe expands spacing, Stack moves complete lines, and Elastic stretches a word before returning it to rest. The main interface is a shallow performance strip beneath a fullscreen typographic stage. Advanced mapping is temporary. Track Atlas remains a different project focused on interpreting a whole track; Type Rave focuses on the visitor's words. Final display font, motion amplitudes, export formats, and microphone scope remain review decisions rather than implemented features.
