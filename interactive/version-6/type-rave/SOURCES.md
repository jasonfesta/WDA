# Sources and provenance

- [DIA — A-Trak Live Visuals](https://dia.tv/project/a-trak/): primary design case study for a parameter-led typographic identity. It informs visual discipline, not a copied wordmark or product UI.
- [GoodFromYou — A-Trak dynamic type](https://www.goodfromyou.com/you/2017/8/9/a-trak-dynamic-type): publisher of the retained [reference image](references/dia-atrak-published-reference.jpg). Design credit: DIA.
- [Inter official site](https://rsms.me/inter/): primary font and licensing reference. Final display-font selection remains open.
- [Web Audio specification](https://webaudio.github.io/web-audio-api/): future audio-analysis planning reference; the linked editor's draft is work in progress.
- [Media Capture and Streams](https://www.w3.org/TR/mediacapture-streams/): primary draft reference for a possible explicit microphone mode.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): future accessibility-review reference.

This expanded pack does not copy an existing product's behavior claims. Breathe, Stack, Elastic, the phrase workflow, mapping limits, output decisions, and interface layout are proposals for Type Rave.

No microphone was enabled, no audio was analyzed, and no typography engine was developed for this pack. The retained reference is existing artwork; all described Type Rave screens and production assets remain future work unless explicitly listed as delivered.
