# Product definition

## Make words perform

Type Rave is a proposed visual instrument for people who enjoy typography, music, and making a strong graphic quickly. The visitor supplies a phrase, then performs its spacing, weight, and arrangement. The result should feel authored through a few deliberate choices. It should not resemble an equalizer with letters substituted for bars.

The primary visitor wants a striking poster-like frame or a short live performance without learning a motion-design application. A secondary visitor wants to explore how one phrase behaves across different rhythms. Both need a small, coherent vocabulary rather than an endless effect library. The product's promise is a clear relationship between an action and a visible typographic response.

## First scope

The proposed first experience contains one phrase editor, three authored behaviors, a prepared original audio loop, pointer manipulation, freeze, and a saved still. Optional microphone input can follow the same behavior mappings. It should never be required to reach the first useful result. A local audio-file source is a separate scope decision, not an automatic requirement of the concept.

Breathe changes spacing in an orderly way. Stack shifts complete lines into rhythmic blocks. Elastic extends a word and returns it to a stable form. Each behavior needs a recognizable resting state. Intensity changes how far a composition travels, not whether the phrase can ever be read.

## Boundaries and distinction

Track Atlas explores a track through multiple visualization modes; Type Rave performs a visitor-authored phrase. BEATFRAME scores rhythmic input; Type Rave has no accuracy meter, health, combo, or winning condition.

The interface must not become a professional animation timeline with sidebars, layers, and property inspectors. The main strip should answer only a few questions: what phrase, which behavior, what input, how much intensity, and whether to freeze or save. Advanced controls can appear temporarily without shrinking the stage.

## Success and open choices

At concept review, a viewer should be able to describe the action-to-response relationship of each behavior and imagine producing a different result with different words. Future success could be measured by time to a meaningful composition and how often visitors save a frame, but no such data exists here.

Before production, decide the display face, maximum phrase length, supported scripts, prepared audio source, exact export scope, and microphone controls. The current deliverable is a detailed graphic and interaction proposal, not a functioning instrument or a generated video collection.
