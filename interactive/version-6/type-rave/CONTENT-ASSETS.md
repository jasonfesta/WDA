# Content and asset inventory

## Existing reference

The delivered visual is [DIA's published A-Trak typographic work](references/dia-atrak-published-reference.jpg), retained from the research library. Credit the design to DIA and the image publication to GoodFromYou, with the primary DIA case study alongside it. This is an influence for disciplined expressive typography, not Type Rave artwork or an interface capture.

The current package contains no new generated Type Rave screens, animated loops, font binaries, sound recordings, or executable assets. Its deliverable is a detailed art and interaction plan. The inventory below identifies what a later approved production phase would need.

## Graphic studies

The core art set should include three behaviors across four useful moments: rest, moderate energy, peak, and freeze. That creates twelve composition studies before adding alternate colors. A coherent set is more valuable than many unrelated effects. Each study should use the same test phrase at first, making the behavior differences visible.

A second phrase set should include a short two-word statement, a longer six-word line, repeated letters, punctuation, accented characters, and an intentionally awkward wrap. These are typography stress cases, not final marketing slogans. Avoid using famous lyrics as default content. Visitors should be able to replace the sample words immediately.

## Interface and source assets

The interface art needs compact phrase editing, behavior selection, intensity adjustment, source choice, freeze, save, and a temporary mapping surface. Separate states are needed for keyboard focus, selected word, live microphone, silence, permission denial, unavailable input, and export error. The stage remains dominant in every state.

Any chosen font requires its family name, version, license, supported scripts, and fallback strategy. A prepared audio loop should be original or otherwise appropriately available, with duration and loop boundaries documented. Its role is to demonstrate a mapping, not to supply an expansive music library.

## Output and handoff

Proposed still outputs should record dimensions, color space, background treatment, phrase, and composition settings. A project-file schema would need versioning and font identifiers before it can promise reliable reopening. Motion export is a separate future decision because it adds timing, encoding, and capture requirements.

Every future asset should have a role, source, approval state, and version. Preserve the reference artwork separately from original compositions. The handoff should make it obvious whether a file is evidence, a proposed screen, a reusable graphic, or a final export. The present pack is sufficient for concept review without pretending that these production assets already exist.
