Scope

This is an art and concept-specification collection, not six working products. Generated images are flattened raster studies. Character turnarounds are modeling references, not meshes or rigs. Audio values, scores, connections and training results shown in art are illustrative. Jet Ski POV and Type Rave currently use clearly labelled existing references; their final original interface art has not been produced.

Each project contains README, PRODUCT, EXPERIENCE, VISUAL-DIRECTION, INTERACTION-STATES, CONTENT-ASSETS, TECHNICAL-PLAN, ACCEPTANCE and SOURCES. Technical plans describe future decisions and do not authorize development.

Review principle

The active experience stays fullscreen. Use direct manipulation, contextual actions, compact edge controls and deliberate setup or pause states. A permanent sidebar must not cover the canvas. Accessibility, motion, error handling and mobile adaptation are specified individually.

Provenance and files

manifest.json records current image dimensions, byte sizes, SHA-256 hashes, exact prompt paths and reference credits. The publication includes 40 generated images, five credited reference images and 40 exact prompt files. Prompt text is preserved; input attachments omitted from this selected collection are not reconstructed or implied to be a standalone regeneration package.

Reference authors and publishers are identified in each project. An included reference or artist study does not imply an endorsement, partnership or transfer of rights. This selection excludes earlier visual studies, historical prototypes, full research archives, downloads and generation scripts.

The HTML files are static reading and image-review artifacts. They can be opened locally; no application service, package installation or external runtime is needed.
