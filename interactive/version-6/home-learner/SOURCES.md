# Sources and provenance

Research reviewed 24 October 2026; Android direction updated 25 October 2026. These sources establish specific precedents and platform constraints; the Home Learner experience is a new proposal.

- [Google Creative Lab — Teachable Machine](https://blog.google/innovation-and-ai/products/teachable-machine/): precedent for gathering examples, training bounded classes and testing. It is not evidence of arbitrary routine understanding.
- [Google Codelabs — TensorFlow.js transfer learning](https://codelabs.developers.google.com/tensorflowjs-transfer-learning-teachable-machine): demonstrates frozen MobileNet features and a learned classifier head. This supports the narrow local-learning option.
- [Google AI Edge — image classification](https://developers.google.com/edge/mediapipe/solutions/vision/image_classifier): category outputs from images/video frames. Temporal completion and task execution are separate proposed capabilities.
- [MDN — getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia): permissioned media input, secure-context requirements and unavailable/denied input behavior. It does not establish compatibility with every head camera.

New images were generated with the ImageGen. They are concept imagery, not actual captures of a working product or real training results. [Art manifest](manifest.json) links the exact saved files and prompts.


Assumptions requiring future evidence: supported headcam transport, practical model size on chosen phones, temporal observation quality, automatic transcription quality, resource savings from worker devices, and any local/cloud deployment choice. No source here is an endorsement, partnership or permission to reuse proprietary product art as original work.


Android V2 grounding:

- [Android Developers — system bars](https://developer.android.com/design/ui/mobile/guides/foundations/system-bars): edge-to-edge content, display cutouts, contrast and navigation insets.
- [Android Developers — accessibility](https://developer.android.com/design/ui/mobile/guides/foundations/accessibility): minimum 48 dp targets and alternatives to gesture-only actions.
- [Android Developers — Material 3 theming](https://developer.android.com/codelabs/m3-design-theming): semantic color/type/shape roles with custom brand expression. The stone/charcoal/citron palette and layouts are original design choices.

The current [art manifest](manifest.json) identifies the four selected Android studies.
