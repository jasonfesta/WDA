# Home Learner — concept pack
Working title · Android V2 · 25 October 2026 · concept and raster art only.

Home Learner is an Android app and mobile companion for teaching from life at home through a head camera, webcam or phone. Demonstrate a bounded lesson, label what matters, review observations, prepare a model version, and test an unseen situation. The current illustration uses “Pack my bag”; it does not imply general task learning or robotic execution.

Start with [Product](PRODUCT.md), then [Experience](EXPERIENCE.md). The remaining briefs cover [visual direction](VISUAL-DIRECTION.md), [interaction states](INTERACTION-STATES.md), [content and assets](CONTENT-ASSETS.md), [technical feasibility](TECHNICAL-PLAN.md), [acceptance](ACCEPTANCE.md) and [sources](SOURCES.md).
