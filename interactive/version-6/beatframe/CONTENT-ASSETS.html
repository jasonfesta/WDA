Content and asset inventory — V2

Current deliverables

The active art consists of desktop V2 and mobile V2. They show the same Magdalena Bay dreamscape with format-specific composition: centered three-lane gameplay, a liquid-chrome portal, peach/periwinkle atmosphere, peripheral cameos, winged eyes, tactile targets and a restrained score display. They are raster concept screens, not software screenshots.

The reference is the official Imaginal Disk poster, designed by Ian Grandjean. Keep that existing artwork separate from generated concepts. The reference file is evidence of the visual era; V2 is a new speculative interpretation. The manifest records this distinction, source URLs, image dimensions, exact prompts and review notes.

Copy and caption rules

Artist and track copy are MAGDALENA BAY and “Image.” The title is confirmed by an official tracklist. The visible score, combo, accuracy and progress are illustrative. Do not derive a tempo, duration, difficulty or chart length from the images. No audio file, performer recording or playable artist track is included.

Suggested gallery caption: “Unofficial BEATFRAME V2 concept — Magdalena Bay / Imaginal Portal. Generated screen design informed by Ian Grandjean's official Imaginal Disk poster. UI values are illustrative; no artist endorsement or playable recording is represented.” Keep the caption outside the artwork so the screen can be assessed cleanly.

Later production inventory

If development is separately authorized, the experience would need an agreed recording, authored chart, difficulty metadata, phrase cues and final target geometry. World production would require separated sky, terrain, portal, cameo, winged-eye and foreground layers, plus responsive crop guides. The current PNGs do not contain editable 3D objects, rigged characters, separated textures or an engine-ready scene.

The interface would need component assets for three notes, three targets, hold treatment if approved, judgments, progress, focus and pause. Additional layouts would include ready, preparation, settings, loading, unavailable-recording and results. Reduced-motion and low-detail variants should preserve the same gameplay hierarchy. These remain a future inventory, not implied deliverables.
