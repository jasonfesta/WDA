# SaaS and dashboard references

Jason Festa’s collection of **20 live application examples**, organized into **48 screenshots**: 24 desktop and 24 mobile. Each example has a base pair; four examples also include an alternate theme pair.

- [All systems, application types, examples, and research sources](SYSTEMS.md)
- [Chat/file audit and capture limitations](AUDIT.md)
- [Image manifest with source URLs, dimensions, and hashes](captures.json)

Each folder under `examples/` contains `README.md`, `desktop.jpg`, and `mobile.jpg`. Alternate themes use `desktop-light.jpg`, `mobile-light.jpg`, `desktop-dark.jpg`, or `mobile-dark.jpg`.

Screenshots preserve the original demo interfaces. Several demos have chart-rendering or mobile-layout limitations, recorded in their notes. These are visual references, not a claim that every package includes a tested production backend. Source links identify the original projects; their code and assets remain subject to their own licenses and terms.
