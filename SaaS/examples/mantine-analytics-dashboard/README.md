## Source and visible evidence

The repository describes a Mantine/Next.js admin template, mock API routes, and demo authentication. Its example data should not be treated as a connected production service. [Source](https://github.com/design-sparx/mantine-analytics-dashboard).

- Cards for sales, visitors, total earnings, and pending orders.
- Revenue trends, weekly sales, and a device comparison chart.
- A task table with dates, status, and assignees.
