## Source and visible evidence

The repository identifies a Mantine, Vite, and TypeScript dashboard template and links to this v1 demo. The selected capture is its Kanban application view. [Source](https://github.com/nedois/mantine-dashboard).

- Columns for Todo, In progress, Read to test, Review, and Done.
- Cards with priority and work-type tags.
- Assignee avatars, comment counts, attachment counts, and Add card controls.
