## Source and visible evidence

The repository identifies a Next.js/shadcn/ui template with multiple dashboard layouts. Its planned multi-tenant support should not be treated as an implemented capability. [Source](https://github.com/arhamkhnz/next-shadcn-admin-dashboard).

- Revenue, new-customer, active-account, and growth-rate cards.
- A Customer Activity chart area with time and segment selectors.
- A searchable customer table with status, billing, plan, and join date.
