## Source and visible evidence

The official kit includes a project-management app. The captured view is its personal workspace overview, rather than a portfolio-wide project summary. [Source](https://www.shadcnblocks.com/template/admin).

- Issues created, assigned, and subscribed to.
- Counts for Backlog, Todo, In Progress, Review, and Done.
- Work-hour analysis, a time tracker, a personal issue table, and a meetings panel.

## Suggested uses — inferred

These associations describe possible reuse, not verified backend capabilities.

- A team member workspace showing assigned work and time allocation.
- An agency delivery or engineering operations interface after connecting project data.
