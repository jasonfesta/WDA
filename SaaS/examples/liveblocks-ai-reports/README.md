## Source and visible evidence

The example documentation identifies Next.js, Liveblocks, and Tremor Raw, and describes embedding a pop-up AI chat in a dashboard. The template UI has separate Tremor licensing noted by the source. [Source](https://liveblocks.io/examples/ai-dashboard-reports/nextjs-ai-dashboard-reports).

- Filters for date range, location, expense status, and transaction amount.
- Transaction amount and count over time.
- Category and merchant rankings, with Reports, Transactions, and Invoices navigation.
