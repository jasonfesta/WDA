## Source and visible evidence

The documentation describes a collaborative issue tracker using Liveblocks and Next.js. It also documents an optional AI assistant; that assistant was not exercised in this capture. [Source](https://liveblocks.io/examples/linear-like-issue-tracker/nextjs-linear-like-issue-tracker).

- A workspace sidebar with Inbox and Issues.
- Issue rows grouped by status, including In Progress and Done.
- Issue labels, dates, and assignee avatars.
