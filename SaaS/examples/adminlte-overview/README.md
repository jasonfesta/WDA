## Source and visible evidence

AdminLTE is a Bootstrap admin template. The public demo supplies sample dashboard data; a connected business backend was not tested. [Source](https://github.com/ColorlibHQ/AdminLTE).

- New orders, bounce rate, user registrations, and unique visitors.
- A Sales Value area chart and visitor map.
- Direct Chat and operational widgets below the overview.
