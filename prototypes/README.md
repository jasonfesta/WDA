# Prototypes

Each prototype lives in its own folder with its source, assets, and setup instructions.

- [Avela - Grok 4.7](Avela%20-%20Grok%204.7/): a React and Vite editorial leather goods shop with product pages, collection filters, and a persistent demo shopping bag.
- [AVELA-GPT6-Astra](AVELA-GPT6-Astra/): a React and TypeScript interpretation of the Avela Nano Banana 2 4K grid, with five complete page layouts, product galleries, search, saved pieces, and a persistent demo bag. Local build preview: `http://127.0.0.1:5186`.
