# AVELA-GPT6-Astra

A complete local React storefront built from the Avela Nano Banana 2 4K website grid.

Saved in [jasonfesta/WDA](https://github.com/jasonfesta/WDA) under `prototypes/AVELA-GPT6-Astra`, alongside the Grok prototype.

From the WDA repository root, run `cd prototypes/AVELA-GPT6-Astra` before the commands below.

## Run

Requires Node.js 20.19+ and npm.

```sh
npm ci
npm run dev
```

Development uses `http://127.0.0.1:5186` with strict port binding. It never stops another server or silently selects a different port.

For the production build:

```sh
npm run build
npm run preview -- --port 5186 --strictPort
```

If port 5186 is occupied, choose a free port explicitly:

```sh
npm run preview -- --port 5187 --strictPort
```

On macOS, inspect listeners with `lsof -nP -iTCP -sTCP:LISTEN`. Build output is in `dist/`. Any static HTTP server can serve it. Hash-based routes work without server rewrite rules.

## Included

- Home: photographic campaign, oversized live “SOFT FORM” type, product stories, editorial notebook.
- Collection: Arc / Fold / Day filters, price sorting, saved pieces, comparison table.
- Product pages: Arc plus supporting Fold and Day pages, galleries, image zoom, quantity controls.
- Our story: the complete studio and craft narrative.
- Care: chapter navigation, care guides, FAQs, and a local repair-enquiry draft.
- Shared search, persistent bag, correct price totals, order preview, community photo viewer, mobile navigation, and local newsletter preview.
- Keyboard-accessible native dialogs, visible focus states, semantic headings, reduced-motion support, and responsive layouts.

## Reference and interpretation

The 4K grid is preserved byte-for-byte. Photographic regions were extracted without stretching and encoded as WebP. `asset-crops.json` records every crop. The hero uses the existing, clean 1681 × 936 Avela campaign photograph from the original workspace so the headline, navigation, and button are real interface elements rather than baked-in pixels.

The reference’s cream, burgundy, terracotta, oversized campaign type, serif editorial headings, alternating photo/text bands, and page sequences are retained. DM Sans and Space Grotesk are bundled with their package licenses; Georgia supplies the reference’s editorial serif character. Malformed generated labels are replaced by readable copy. The staged source photography retains its original image detail; 4K describes the entire grid, not each extracted photograph.

Arc uses the source price of **$420** and measurements **30 × 22 × 10 cm**. Fold ($380) and Day ($480) prices are illustrative values for the prototype. Their measurements are deliberately left unspecified. Fictional customer testimonials are replaced by brand editorial copy.

## Demo boundaries

This is a fictional, local concept storefront. There is no payment service, order backend, stock system, or outbound email.

- Checkout displays an order preview; it never charges or claims to place an order.
- Newsletter signup and care drafts are explicitly local-only.
- Bag, favorites, signup, and care draft persist in browser local storage. Clear this site’s storage to reset them.
- Shipping and returns copy explains that policies will be confirmed before a live launch.
