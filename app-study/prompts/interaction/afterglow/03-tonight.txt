ENTRY: Set my evening / Tonight tab
STATE: Afterglow wordmark and a settings gear. Heading "Tonight can be simple". Amber moon vignette. "10:30–10:45 pm" and "15 minutes, just for you". Three spacious rows: "Breathe" / "2 min"; "Stretch" / "5 min"; "Read" / "8 min". All incomplete. CTA "Begin with two minutes". Quiet link "Change my evening". Bottom tabs Tonight / Rituals / Sounds, ONLY Tonight active.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: Use the resting bloom; do not replay the welcome effect.
ACTIONS: Ritual row hover adds a warm tint; empty completion rings do not fill on hover. Begin opens the real ritual player. A completed ritual fills its ring over 180 ms after completion state saves.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: Keep all three items readable in one normal scroll region; return from player to the invoking item. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.
