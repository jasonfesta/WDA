ENTRY: Settings tab
STATE: SOUL header; cream background with blue accent and tiny sun. Heading "Make the forecast yours". Sections "Units": Temperature °C selected over °F; Wind km/h selected over mph; Time 24-hour selected over 12-hour. "Home city" row Lisbon. "Location" row Manual. "Golden-hour reminder" switch OFF. "Reduce motion" switch ON. Links "Privacy" and "Data sources". Bottom Today / Places / Settings; ONLY Settings active. Do not add a Save button: these preferences save immediately.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: Reduce motion is pictured ON: no cloud drift, ray rotation or transition travel.
ACTIONS: Unit selection updates all derived values. Reduce motion immediately freezes the scene and persists; switching it off does not force a replay. Privacy and sources are route links.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: No GPU frame loop while this still screen is displayed. Return from sheets restores Settings scroll. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.
