ENTRY: Places tab / city selector
STATE: SOUL, sky-blue header, heading "Places you keep an eye on". "1 saved place". Large cream row with small orange sun "Lisbon" / "28° · Sunny" and check indicating current city. Search field "Add another city". Below clear label "Suggestions" and rows "Porto, Portugal +" and "Faro, Portugal +". Do not show suggestions as saved places. Bottom Today / Places / Settings; ONLY Places active. Lisbon has an explicit More menu. Suggestions show illustrative 28° Sunny values; these are fixture values, not live forecasts.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: Weather group stays still while choosing cities.
ACTIONS: Saved-city rows tint on hover; More and Add are independent targets. Add Porto changes saved count only on success, with a 180 ms row appearance. Avoid duplicating a saved city.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: Keep list position after menu close; no carousel or automatic city switching. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.
