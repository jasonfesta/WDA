ENTRY: First launch
STATE: Brand SOUL, soft sky blue filling canvas and a tactile orange sun/cloud vignette. Title "Find the light in your day". Body "Weather and daylight, in one calm view." Search field label "Choose a city", value "Lisbon". Selected result "Lisbon, Portugal" with check. Primary "Use Lisbon". Secondary "Use my location". Marker "1 / 2". No bottom tabs. Porto and Faro appear as unselected alternatives.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: A 4-second sun/cloud settling pass on first entry, unless system reduced motion is enabled.
ACTIONS: Search field focus freezes the 3D scene. Result hover tints without selecting; activation checks Lisbon. Use Lisbon proceeds with its ID; Use my location has an explicit permission route.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: No camera tilt from scrolling or device orientation. Keyboard opens over a still scene. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.

EVERY CONTROL


Implement soul.01.01 (Choose a city) as combobox. Input: Type/search then select. Result: Debounced search with loading/no results/error; keyboard result list, explicit selection. Target: self. Accessible combobox/listbox, clear action, arrow navigation, Enter select, Escape close. Distinguish query from selected record ID. Hover: 120 ms border tint. Focus: immediate visible outline with stable label; no scale or placeholder movement. Touch opens the native editing affordance. Freeze decoration during editing. Preserve draft, selection and keyboard position; validate without shaking the field.

Implement soul.01.02 (Lisbon / Porto / Faro result) as option. Input: Tap/click or Enter. Result: Set draft city ID and label; do not rely on typed name alone. Target: self. Listbox option with aria-selected; selecting updates the draft record ID and visible label. Hover: 120 ms outline/tint on the target. Focus-visible stays distinct from selected. Press: 80 ms tint; selection changes only on activation. Selected fill/thumb changes in 140 ms after accepted state; permissions and save failures retain the last valid state. Reduced motion is immediate.

Implement soul.01.03 (Use Lisbon) as submit. Input: Tap/click or form Enter. Result: Save selected city draft and continue; no location permission required. Target: 02-preferences. Validate, focus first invalid field, preserve draft; disable duplicate submission while pending. Success commits once; failure offers Retry. Hover: 120 ms contextual fill/border tint. Focus: immediate visible outline. Press: 80 ms darker tint without layout shift. Exit/canceled press restores rest. Activate on release/keyboard once; preserve labels while pending, suppress duplicate submits, and show explicit success/error. No decorative animation gates the action.

Implement soul.01.04 (Use my location) as button. Input: Tap/click; Enter or Space. Result: Ask only on tap; denied/timeout returns to city search with explanation. Target: aux:location-permission. Button with visible focus; pending state only for asynchronous work. Return focus after a sheet closes. Hover: 120 ms contextual fill/border tint. Focus: immediate visible outline. Press: 80 ms darker tint without layout shift. Exit/canceled press restores rest. Activate on release/keyboard once; preserve labels while pending, suppress duplicate submits, and show explicit success/error. No decorative animation gates the action.

Never rasterize UI text or controls into a background video. No OS status bar or home indicator. Preserve native aspect ratio. Auxiliary destinations follow the app ledger, not another unrelated app screen.
