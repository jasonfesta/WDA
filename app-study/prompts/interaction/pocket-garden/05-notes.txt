ENTRY: Notes tab / Add observation
STATE: Pocket Garden, heading "The things you notice". "Pip · Kitchen window". One subtle botanical leaf illustration in corner. Labeled editor "New observation" with exact text "Pip has two new leaves." Optional outlined control "Add a photo". Primary "Save note". Secondary "Cancel". Quiet footer line "Your notes will grow here." Bottom Garden / Care / Notes; ONLY Notes active. Do not show a second copy of the unsaved note in history.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: Writing pose is a still poster while composing.
ACTIONS: Textarea caret is native; photo attachment fades in over 160 ms after selection. Save replaces the draft with one dated note after success; Cancel asks before discarding a dirty note.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: Keep focus and cursor position stable while the keyboard opens. Never animate the field or move the text while typing. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.
