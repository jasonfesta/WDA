ENTRY: Open my home / Today tab
STATE: Home Note and small Avery avatar. Heading "Today at Maple House". Date "Friday, 19 June". Small clay house vignette. Three readable loose rows: "15:15 School pickup" / "Avery"; "16:00 Peanut-free snack" / "Ready to pack"; "19:30 Choose a story" / "On the shelf". Small context note "Keep the handover simple." Primary "Add a note +". Bottom Today / Notes / People; ONLY Today active.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: The small house and Avery portrait are still.
ACTIONS: Agenda rows use a soft peach tint on rollover. Optional object tilt is limited to 2 degrees once during pointer entry, never the text. Add a note opens the editor; the schedule is unchanged until save.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: Preserve agenda scroll on detail/editor return. No motion is applied to time labels. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.
