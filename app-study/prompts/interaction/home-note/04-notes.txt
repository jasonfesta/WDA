ENTRY: Notes tab / Add a note
STATE: Home Note. Heading "The handover notebook". Three cream rows with small tactile icons: "Blue cardigan in the hall"; "Library books due Friday"; "Snack box is packed". First row expanded with "On the lower hook beside the front door." and "Added by Avery". Under it small actions "Edit" and "Mark read". Primary "Add a note +". Bottom Today / Notes / People; ONLY Notes active.
DISPLAY: Brand, headings, body copy, background texture, decorative vignettes and dividers are noninteractive. Read meaningful copy in document order; decorative artwork uses empty alt. OS chrome is intentionally omitted from exports; production safe-area insets belong to the app shell. Step markers communicate progress and are not buttons. Numeric totals derive from saved data or the explicitly described draft. Any exceptions appear in the control ledger.
AMBIENT: House and author avatars are still while reading.
ACTIONS: Accordion expands in 220 ms; chevron reflects aria-expanded. Edit and Mark read remain separate buttons. Mark read updates its label and saved state only after success, with no celebratory movement.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: Opening a note does not mark it read. Preserve the expanded record and return focus after editing. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.
