ACTIONS: Primary CTA fill darkens on hover/press. Join household remains an explicit link. Illustration cards do not tilt or behave like buttons.
SCROLL/RETURN: One vertical scroll region. Preserve the airy spacing; at small heights or large text allow scrolling instead of scaling text down. Keep the bottom destination navigation above the safe area when present, and add content inset so it covers nothing. Keyboard opening scrolls the focused field into view; closing it restores the prior position. No horizontal paging gesture changes destination. Motion layer: Natural scroll; no layered portrait parallax. Use normal document scroll; never hijack scrolling or move the foreground type with a background effect. Decorative layers stay inside their illustration region. Suspend them when offscreen, document-hidden, an editor has keyboard focus, or a modal covers the screen. Return to the same phase without catch-up bursts.

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.

Button with visible focus; pending state only for asynchronous work. Return focus after a sheet closes. Hover: 120 ms contextual fill/border tint. Focus: immediate visible outline. Activate on release/keyboard once; preserve labels while pending, suppress duplicate submits, and show explicit success/error. No decorative animation gates the action.

Implement home-note.01.02 (I have an invitation) as link. Input: Tap/click; Enter. Result: Open invitation-code entry; invalid/expired code allows retry; successful acceptance routes to Today. Target: aux:join-household. Route link; announce destination heading after navigation and restore scroll on Back. Hover: 120 ms underline/tint. Focus: immediate outline. Active route selection is a no-op; preserve route scroll/drafts.

Never rasterize UI text or controls into a background video. No OS status bar or home indicator. Preserve native aspect ratio. Auxiliary destinations follow the app ledger, not another unrelated app screen.
