ROLLOVER & TOUCH

Touch is primary. Enable rollover only for (hover: hover) and (pointer: fine). Every hover cue has a focus-visible equivalent; no action or information is available only on hover. Pointer exit restores the resting style without changing selection. Use native buttons, links and labeled fields, not clickable artwork.

TIMING & FEEDBACK

Proposed tokens: hover 120 ms; press tint 80 ms; focus outline immediate; route crossfade 160 ms; small state changes 180 ms; expanded content 220 ms. Ease with cubic-bezier(0.2, 0, 0, 1), without overshoot. No animation delays navigation, saving or focus.

REDUCED MOTION

effectiveReducedMotion = system preference OR saved app preference. When true, use a static poster, freeze shader time and 3D poses, remove parallax, and apply state changes immediately. Functional pointer-following remains direct, with no inertial or settling animation. Text and status feedback remain complete.

HOW IT BECOMES REACT

Build DaylightArc as SVG over a still landscape. Given valid sunrise, sunset and current instant in Europe/Lisbon, compute p=clamp((now-sunrise)/(sunset-sunrise),0,1). Map x=cx-r*cos(pi*p), y=cy-r*sin(pi*p); derive remaining minutes=max(0,ceil((sunset-now)/60000)). The review fixture is 18 June 2026 at 18:00, sunrise 06:12, sunset 20:58, so remaining=178 minutes and p=708/886. State is canonical instants with timezone-aware formatting; do not rely on unzoned date parsing. On user-selected date/place change, interpolate the marker for 400 ms only when both data sets are valid. Do not animate a whole sunrise on entry. Minute ticks update the position directly; no perpetual render loop. For past/future dates say Daylight duration instead of live time left, using noon as the preview marker with a Preview label. Handle night, missing data and polar conditions explicitly.

Calendar Permission

Explain read-only calendar import → select provider/calendar → explicit Connect. Show loading and connected status only after success. Denied, cancelled or unavailable returns to manual planning. Imported items keep source IDs; editing read-only events opens the source or creates an explicitly separate local copy.

City Search

Labeled city search, clear-query button, result list with country and timezone, loading/no-results/error states. Selection uses a stable city ID. Add/Use is explicit; duplicate saved city selects the existing record. Cancel restores the invoking route and draft.

Date Picker

Labeled month/year and date grid, previous/next month and Today. Keyboard date navigation and typed-date alternative. Apply selects day in Europe/Lisbon; Cancel preserves date and scroll.

Daylight Detail

Show sunrise, sunset and daylight window as readable times with timezone/source. Optional reminder requires its own explicit action. Close returns to the initiating row/arc; polar-day/no-data states need explanatory text.

Delete Plan

Confirm Delete / Keep plan. Success removes the selected record and returns to Today with Undo; failure keeps the form and record. Undo restores the original ID and times.

Discard Plan

Keep editing returns to the dirty form. Discard restores the saved 18:30–19:05 / 35-minute walk and returns to the caller. Never commit the displayed 40-minute draft implicitly.

Place Detail

Show saved name, description and location with Edit and Use in a plan. In editor-picker mode, Select this place returns its ID to the existing draft. Back never discards that draft.

Place Editor

Labeled name (1–80), note (0–500), city/location, Save and Cancel. Create increments saved count once; edit updates the same ID. Duplicate candidates offer Use existing / Keep separate. Dirty Cancel confirms discard.

Plan Editor

Use the plan editor for the selected record, including dinner; it carries recordId and returnTo. Save updates that record only. Cancel preserves saved values; errors keep the draft.
