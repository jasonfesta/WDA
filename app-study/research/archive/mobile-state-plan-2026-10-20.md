Stable tab sets:

- Home Note: Today / Notes / People / Home.
- Afterglow: Tonight / Rituals / Sounds / Rhythm.
- Pocket Garden: Garden / Care / Notes / Profile.
- Petal: puzzle controls and library; no unrelated app tab bar.
- Sol: Today / Places / Settings.
- Daybook: Today / Week / Places.

Entry actions: create household → continue → open handover note → people/invite; set evening → open ritual → open sound → rhythm; welcome → garden → plant → care → notes; puzzle → hint/pause/solve/library; Today → hour/places/light/settings; Today → add/save plan/week/places.
