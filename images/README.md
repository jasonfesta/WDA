# WDA image library

A collection of website layouts, mobile screens, components, and color references maintained by Jason Festa.

| Folder | Images | Contents |
| --- | ---: | --- |
| [Colors](colors/) | 54 | 12 generated textures and 42 original color/material references |
| [Mobile](mobile/) | 6 | Exported mobile app screens |
| [Components](components/) | 10 | 6 edited components and 4 earlier versions |
| [Website](website/) | 6 | Generated website layouts |

Earlier component versions are in `components/earlier-versions/`. Colors are split into `colors/generated-textures/` and `colors/original-references/`.

The 76 PNGs retain their original contents. [The manifest](manifest.json) records image titles, categories, and SHA-256 checksums. Original reference screenshots are labeled separately from generated outputs.
