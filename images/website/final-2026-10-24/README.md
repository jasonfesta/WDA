## File fidelity

All 20 images are byte-for-byte copies of their source artwork. Nothing has been regenerated, upscaled, resized or recompressed for this publication. The ZIP contains image files only. The repository adds a Markdown index and a JSON inventory for navigation and provenance; it adds no HTML, CSS, JavaScript or website implementation.

Nine active mobile images are at least 780 px wide. The unchanged AVELA mobile is a legacy 390 px export. Desktop originals range from 725 to 1536 px wide, so they are not 2× exports for a 1440 px desktop display. Exact dimensions, source paths and SHA-256 checksums are in the inventory.

Publishing the current images does not certify production behavior or resolve outstanding review feedback. Existing reference research and alternate options remain outside this download.
