## Interaction coverage for companions

PDP: gallery selection/zoom, colour and URL change together, add pending/confirmed/error, unavailable variant and back restoration. Bag: quantity update and rollback, remove/undo, empty recovery, price/stock revalidation, close returns focus. Checkout: guest contact, address validation, recalculation, hosted payment, explicit review before commitment, decline and unknown-outcome reconciliation. Confirmation: real acknowledged receipt only, pending/preparing/dispatched states, actual tracking URL only after dispatch, safe guest access recovery. These are proposed behaviors; image concepts do not implement them.
