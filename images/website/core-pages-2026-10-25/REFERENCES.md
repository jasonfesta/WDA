## Mobile composition

[W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) supports adapting content to a single reading direction without loss of information. Our visual decision is a real one-column phone layout with vertical product, process and guide sequences, rather than a scaled desktop layout.

[W3C Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) addresses target size and separation. This collection aims for visually generous 44–48 logical px controls, 28–32 px side gutters, and 80–112 px pauses between major mobile chapters. Those are authored art-direction targets, not measured CSS or an accessibility certification of raster images. Apple's layout page required JavaScript and its linked Markdown fetch failed; no unobserved Apple-specific rules are asserted.

## Color and layout

Air comes from spacing, simpler hierarchy and fewer containers. It does not require washing every site white. Pale blue, sage, citron, golden apricot, copper and peach retain distinct brand moods. Off-white is a supporting surface. Beige is not the universal background.

Each new destination is complete from a compact site header to a concise footer. A catalogue, product page, story, inquiry and guide must have different opening architecture. No required testimonial, social strip, giant repeated wordmark or card grid is imposed across the collection. Raster text is illustrative; prompts and measured image sizes remain available in production records.
