[Manifest](manifest.json) records exact prompts, ordered input references and hashes, generation dimensions, assembly, and visual QA.

Mobile artwork is generated as two production sections and joined into one image after proportional downscaling to the smaller native width. No upscaling or nonuniform stretching. Desktop output preserves native resolution.

Warm, light color grounds and unboxed photographic compositions follow the approved homepage identity. Inquiry and collection pages show blank request forms, without fabricated confirmation, pricing, opening hours or addresses.

These raster mockups communicate the design. They do not establish browser behavior, accessibility or production implementation readiness.
