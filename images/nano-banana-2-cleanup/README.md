# Nano Banana 2 Cleanup

Maintained by [Jason Festa](https://github.com/jasonfesta). This collection contains 9 website sheets, 6 mobile application sheets, and 6 component sheets: 135 designs in total.

Every folder includes the native output, the exact input image, the cleanup prompt, a preview, and reproducible model settings. All edits used `fal-ai/nano-banana-2/edit` with the **4K** setting for the whole sheet. PNG outputs are the original downloaded bytes; none were stretched, cropped, or retouched after generation.

These are review outputs. Several contain inaccurate text or UI states, and Avela, Virel and Usage have significant aspect-ratio changes. See [review notes](review-notes.md) and per-sheet metadata before using them as implementation references.

The [cleanup brief](cleanup-brief.md) records the per-layout content and consistency requirements. All collection labels use Nano Banana 2 Cleanup.

The first pass returned 20 images; one authorized Spriglet retry completed the collection. There were 22 submitted requests including the failed attempt. At the published $0.16 per 4K edit, the estimated maximum is $3.52; actual billing was not available. The failed request has not been assumed free.
