## Research and scope

Original Firecrawl, Factory, Cognition/Devin, Resend and Linear public pages and documentation informed page purposes and UX decisions. The companies, copy, product context, composition, sample data and footers remain original. Reference captures are saved separately in the local study archive and are not included as concept images.

The 12-view cap covers primary journeys. Legal pages, support articles, and every possible account substate are not separate image deliverables. Coverage records identify where navigation topics are represented by existing pages or app sections.

These are raster design studies, not implemented product interfaces. Fonts and small graphical details are visual approximations. Prices, policies, names and workflow state are fictional examples. Every new image was visually reviewed for selected navigation, visible state, responsive layout and full bounds.

The PNGs preserve native geometry. Where a long page uses multiple renders, only proportional assembly is used; no stretching or artificial detail claims. Exact selected prompt chains are included. All input attachments, source captures, native renders and rejected drafts remain in `tech/moodboard-v6/expanded/`; this selected collection is not a complete regeneration archive.
