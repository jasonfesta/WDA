Each company folder contains four PNGs and a `prompts/` folder with the exact saved
prompt text for each view. Homepage prompt files contain the selected segment
prompts and any required correction prompts in order. [manifest.json](manifest.json)
records file paths, dimensions, SHA-256 checksums, fonts and available sample state.

## Selected direction

- **Rillset:** open white layouts, restrained orange, dataset versions and schema review.
- **Avenor:** entirely light surfaces, release planning and approval controls.
- **Neral:** quiet typography, model evaluations and evidence review.
- **Oriel:** neutral black, publication previews, an airy app and scheduling component.

The companies, copy, product context, layouts and footers were created for this
collection. The images use plain company wordmarks, with no reference-company,
customer or vendor logo strips.

## Scope

This folder contains only the selected V6 concepts. It excludes V1–V5 concepts,
reference captures, rejected renders, source segments, download archives and gallery
implementation files. Those remain in the local study archive at
`tech/moodboard-v6/`; the existing local review gallery remains available at
`http://127.0.0.1:8782/tech/moodboard-v6/`.

Built-in ImageGen produced the raster designs. Long pages were assembled with
proportional downsampling and vertical joins; no stretching or upscaling. Fonts
and chart geometry are raster approximations. Exact input attachments and full
render provenance remain in the local archive; this selection is not a standalone
regeneration package.

All 16 final files were checked against the approved V6 image hashes. The local
gallery passed full-resolution viewing, mobile layout, download, and comparison
checks. Earlier image versions remain preserved locally.
