# WDA

## Warm moodboard

[Live moodboard](https://warm-moodboard.vercel.app) · [App source](warm/moodboard/) · [Build brief](warm-moodboard-build-brief.md)

An interactive React moodboard with 42 selected references, ten warm color directions, live interface examples, and six textured WebGL studies.

```sh
cd warm/moodboard
npm ci
npm run dev -- --port 5178
```

Run `npm run build` from the same directory for the production build. The app's README includes deployment instructions and details about the source imagery, fonts, and interactions.

The repository also includes the [reusable build prompt](original-image-prompt.md), [original prompt history](warm-moodboard-original-prompt.md), and the selected 42-image archive, `warm-moodboard-images.zip`.
