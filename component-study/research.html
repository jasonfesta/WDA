Official references / Read 21 October 2026

Patterns to build from.

W3C — tabs pattern ↗

A selected tab is connected to its visible panel. Horizontal tab lists use Left/Right arrows; manual activation uses Enter or Space.

Sol day selection, Roam plan previews and Kiln reporting periods use one active panel. Focus and selection are tracked separately.

W3C — checkbox pattern ↗

A checkbox exposes its checked state and a readable label; Space toggles it.

Gather uses one native checkbox per person, with count and avatar summary derived from selected IDs.

W3C — radio group pattern ↗

Radio groups express a single choice. Arrow keys move between options and Space selects.

Courtyard keeps exactly one active material, with a visible ring and its text name.

W3C — modal dialog pattern ↗

A modal moves focus inside, contains keyboard focus, closes on Escape and returns focus appropriately.

Roam review and Kiln plan details need explicit close/cancel paths with trigger focus restoration.

W3C — disclosure pattern ↗

A disclosure button exposes its expanded state and toggles a connected content region.

Gather opens by activation, not hover; its trigger communicates open or closed.

Radix — Popover build example ↗

The documented primitive includes controlled state, placement and collision handling, focus management and dismissal options.

Use a tested popover primitive for Gather and Sol options, retaining the existing material art and layout.

Radix — Toggle Group build example ↗

The example supports controlled state, single or multiple toggles, orientation and keyboard navigation.

A useful implementation reference for compact controls. Courtyard still uses radio semantics because it requires a choice.

Stripe — subscription pricing table ↗

The pricing table displays plans and takes a chosen option into Checkout. Completion is a separate step.

Roam previews and compares plans, then explicitly reviews the chosen price. Selection alone does not subscribe.

Supabase — usage documentation ↗

Usage documentation separates resource categories and explains what is measured and how it is calculated.

Kiln needs explicit units, denominator labels and category details. This is a structure reference, not a copied pricing model.

W3C — complex images and charts ↗

Complex graphics need a short description plus a longer textual equivalent of their essential information.

Kiln exposes a data table and values in text; hover tooltips are supplemental.

MDN — aria-current ↗

aria-current identifies the current item within a related set, including the current page.

Folio uses navigation links and aria-current="page" for routes. Use tabs only if switching local panels.

Apple — Weather guide ↗

The guide shows current conditions, forecast exploration, location selection and configurable weather units.

Sol retains a compact four-day surface, with unit conversion and a separately opened location control.

React — choosing state structure ↗

React recommends avoiding contradictory, redundant and duplicated state.

Derive selected counts, button labels, usage totals and visible panels from stable IDs and shared data.

Motion — accessible animation ↗

Motion supports system reduced-motion preferences and replacing substantial movement with simpler feedback.

Disable object drift, parallax and transform flourishes under reduced motion; keep selection and focus feedback.
